# MadGAA-Lab Website

Website for MadGAA-LAB, an open research lab building multi-agent simulation and evaluation tools for healthcare AI.

Live at https://madgaalab.org

## Project Structure

- `index.html` - Home
- `team.html` - Team
- `projects.html` - Projects
- `capabilities.html` - Research areas
- `logos/` - Logo assets
- `picture/` - Image assets

## Local Preview

Open `index.html` in a browser to preview locally.
